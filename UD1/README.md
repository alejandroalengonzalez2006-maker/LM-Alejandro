# Documentacion UD1 Lenguaje de marcas

## Introducción a Lenguajes de marcas

## Definicion 

Un lenguaje de marcas organiza información mediante unas sintaxis basada en marcas o etiquetas.

### Clasificacion del lenguaje de marcas

|Tipo|Uso|Ejemplos|
|----|---|--------|
|Presentación|Dar formato a documentos de texto|HTML, CSS|
|Intercambio de la información|Almacenar información de forma ordenada|XML, RSS|
|Documentación|Documentar proyectos|Markdown, wikiTex|

## Instalación y configuración del entorno

1. Instalamos [VS Code](https://code.visualstudio.com/)
2. Istalamos los siguientes plugins:
   
|Nombre|Uso|
|------|---|
|XML|Se usa para editar, validar y dar formato a archivos XML.|
|Markdown|Permite escribir, editar y visualizar archivos de documentación|
|Live Preview|Te permite previsualizar tus páginas web sin tener que abrir el navegador|
